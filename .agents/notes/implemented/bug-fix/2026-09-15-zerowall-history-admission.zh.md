# Agent Note: 移除能力管理后的 ZeroWall 历史读取兼容

Status: implemented

[English](2026-09-15-zerowall-history-admission.md) | 中文

## 问题

已发布的 ZeroWall 会话包含必需的 `zerowall/capabilities/selection` 事件。移除界面插件也移除了运行时登记，持久化层因此拒绝加载历史。生产构建会内嵌独立的事件目录，仅在基础插件登记名称仍不能修复读取。

## 决策

Session 类型声明保留该旧事件，生成的目录将它纳入各个构建后的读取器。事件只保留在日志中，载荷和序号保持不变，继续会话使用当前工具配置。这条兼容声明不增加事件生产者、界面模块、工具执行器、模型消息或新的会话格式代际。

## 考虑过的替代方案

**运行时登记**无法更新其他包内嵌的目录。**跳过全部未知事件**可能丢失未来格式的必需语义。**修改用户日志**会改变历史记录，并要求每台安装单独迁移。

## 后果

ZeroWall 分支持续维护这条历史事件声明。其他未知必需事件仍然报错。持久化测试覆盖读取和追加，并确认原始字节不变；桌面包检查使用实际构建的持久化模块验证读取。用户私有历史可通过本地副本验证，不提交其内容。
