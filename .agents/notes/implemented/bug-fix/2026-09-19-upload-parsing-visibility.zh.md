# Agent Note: 上传解析可见性

Status: implemented

[English](2026-09-19-upload-parsing-visibility.md) | 中文

## 问题

基于回执授权的文档提取可能需要数分钟。始终显示上传中会隐藏已经完成的传输，并阻止用户在提取期间发送提示词。

## 决策

字节上传成功后，对话控制器立即发布就绪的回执。独立可观察的准备状态使输入区附件卡片准确展示进度。提交先创建本地回显，再等待提取，然后通过既有 Session 提示词契约发送回执。准备失败会撤回回显并恢复可编辑草稿。移除、重试和销毁会中止操作所有者，使迟到的解析响应无法覆盖新结果。取消提交会解除等待，但不会取消仍可复用的草稿解析。

设置外壳采用紧凑分组样式，不注册配置文件操作。Web 启动公开 loading、ready 和 failed 文档状态，使桌面端在插件激活和渲染器挂载完成前持续显示品牌启动页。

## 考虑过的替代方案

**提取完成后才发布上传完成状态。** 这会混淆传输和解析，并阻止所需的即时卡片与排队提交行为。

**提取完成前发送提示词。** Host 可能在文档文本尚未准备好时接收未经补充的回执。在本地回显后等待，能够保留回执校验和提取内容补充流程。

## 影响

除非解析器提供进度，否则解析百分比保持不确定状态。待提交状态仅存在于客户端，不改变持久化 Session 格式或模型输入。原始文件及既有回执授权仍是事实来源。
