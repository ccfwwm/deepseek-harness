# Agent Note: 桌面单会话删除

Status: implemented

[English](2026-09-17-single-session-desktop-deletion.md) | 中文

## Problem

ZeroWall 原先为释放 Windows 会话日志句柄，在将一个会话移入回收站前停止并重启整个 Host，导致界面重载并中断独立工作。

## Decision

会话控制器保留 Agent 工厂返回的释放句柄。删除准备阶段阻止目标会话的新操作、等待已接收操作收尾、拒绝运行中的目标或子任务、关闭历史观察、释放自身拥有的 Agent，并清除派生投影缓存。JSONL 后端解析当前或历史日志实际所在目录。

桌面端确认一次，校验目标位于会话存储内，将目录移入系统回收站，再用准备令牌提交。仅成功提交发布删除事件。重复提交幂等；撤销会解除锁定并通知客户端重新打开历史。若文件已不存在，撤销会确认删除结果，而不会恢复一个不存在的会话。

删除当前会话时，客户端选择最近的其他普通会话；删除最后一个会话则清空选择。删除其他会话保留当前 Session 实例。工作区文件和历史科研产物不变。

本决策补充[工作区注册删除](2026-07-27-workspace-registration-deletion.zh.md)，后者仍只移除工作区注册，没有被取代。

## Alternatives considered

**重启 Host。** 会切断独立会话连接并重新加载界面，因此不采用。

**修改私有注册表。** 移除对象不会按顺序释放作用域服务和持久化句柄，因此不采用。

**删除固定日志文件。** 当前、历史和压缩日志共用目录，但文件名可能不同，因此不采用。

## Consequences

该桌面操作只支持提供目录解析能力的文件存储。会话控制器不能释放其他服务拥有的 Agent。删除准备令牌只保存在进程内；重启 Host 会丢弃准备状态，文件系统仍为事实来源。空闲子任务的历史保留，运行中的子任务会阻止删除父会话。

针对性 Host 和 Client 测试覆盖单目标释放、忙碌拒绝、冷存储、令牌校验、重复提交、选择回退和延迟缓存写入。桌面测试覆盖取消、回收失败与路径限制。没有新增模型工具、提示词或 token 开销。
