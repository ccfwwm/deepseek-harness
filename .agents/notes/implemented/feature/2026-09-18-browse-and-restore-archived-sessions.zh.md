# Agent Note: 浏览与恢复归档会话

Status: implemented

[English](2026-09-18-browse-and-restore-archived-sessions.md) | 中文

## Problem

归档将 Session 从普通列表和搜索中移除，却没有提供再次找到它的入口。桌面标题区样式如果命中侧栏容器而非标题，也会隐藏历史记录。

## Decision

Workspace 浏览器在展开和折叠的侧栏中提供归档对话框。它读取已有 Session 和 Workspace 快照，按标题或 Workspace 名称过滤，并允许打开归档会话而不隐式恢复。恢复复用归档命令，传入可选的 `archived: false`；省略该值仍执行归档。注册表写入串行化和已有归档集合流保证恢复持久化，成员关系保持不变。失败可见并可重试。

侧栏为根节点、折叠状态和标题提供明确标记，供桌面窗口样式使用。标题留白不得改变列高度或历史区域的弹性空间。

## Alternatives considered

**在普通历史中显示归档。** 这会失去归档的作用。单独且始终可达的入口保留普通浏览行为，同时方便找回会话。

**打开时自动恢复。** 查看会话不应悄悄改变其组织状态；恢复是显式操作。

## Consequences

已有归档数据无需迁移。归档搜索覆盖标题和 Workspace 名称；普通历史保留内容搜索。单元测试覆盖持久恢复、串行修改、幂等性、过滤、导航和重试。打包桌面回归覆盖重启后的历史、设置位置，以及通过真实 RPC 路由恢复归档。
