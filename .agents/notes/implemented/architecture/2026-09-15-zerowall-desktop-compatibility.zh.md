# Agent Note: ZeroWall 桌面兼容

Status: implemented

[English](2026-09-15-zerowall-desktop-compatibility.md) | 中文

## Problem

已发布的 ZeroWall 会话包含上游历史清单之外的文件解析元数据、文件审查标记和插件选择事件。原生上传回执还绕过了产品解析器，而替换后的审查渲染器将文件块显示为 JSON。

## Decision

历史读取器接纳已发布的确切 ZeroWall 事件名和附件字段，校验其基本类型，并在相邻迁移中保留数据。未知字段仍被拒绝。打开历史记录不会改写源代文件。

会话上传队列等待产品可选的、基于回执授权的解析器完成后，才将文件标为就绪。会话提交先解析回执，再从 Host 服务读取解析元数据。客户端提供的解析文本不能替换该权威结果。解析不可用时，原始回执仍可使用。共享用户消息气泡公开导出，使审查插件保留原生附件卡片及文件操作。

侧栏底部始终保留设置入口，快捷入口的展开状态独立于侧栏宽度保存。设置外壳处理产品分区跳转事件，包括微信状态入口。

## Alternatives considered

**原地改写用户日志。** 历史文件是不可变证据，迁移失败必须可恢复，因此拒绝此方案。

**恢复内联文件提交。** 原生 Agent 绑定回执能够证明上传归属，因此拒绝此方案；解析集成应在授权之后执行。

## Consequences

产品分支维护明确的历史兼容项和可选 ZeroWall 集成点。聚焦的历史、上传和渲染测试覆盖这些行为；打包后的 GUI 检查覆盖完整组合。
